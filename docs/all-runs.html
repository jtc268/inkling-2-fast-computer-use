Weight-space programming

We edited four rows in Inkling 2 Mini’s output matrix, model.llm.unembed.weight, without additional training. We swapped the rows for answer text (200004) and thinking (200008), then adjusted the rows for the click command C (34) and end of generation (200006). A byte comparison found 9,192 changed BF16 values across those four rows. Weight audit

Method

Both checkpoints ran in MLX and read visible text and numbered controls in Brave. We reset the storefront, warmed each model and used the same prompt, greedy decoding, reasoning effort (none) and cursor timing. Total time includes inference and browser actions. We developed the edit on this task and reversed model order for the second run.

Verify the edit

The output rows for the answer and thinking markers exchanged places. Exactly 4,596 BF16 values changed. On one loaded model, restoring the rows reproduced all 120 original form-response tokens.

Prefilling the original model’s answer channel also worked. On a separate development case it took 7.57 seconds, compared with 6.94 seconds for the edited model using the shared prompt.
