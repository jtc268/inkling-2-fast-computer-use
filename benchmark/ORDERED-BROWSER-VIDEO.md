# Browser benchmark in order

[Watch the 1:49 film](https://jtc268.github.io/inkling-2-fast-computer-use/browser-benchmark-in-order.mp4). It contains 30 task chapters, starting with form and cart, followed by five MiniWoB++ tasks and 23 graded WebArena IDs. Each task appears once. The film selects one recorded case per task and identifies the checkpoint used. Full measured times appear beside each arm. Paired successes share the same elapsed clock whenever timing markers are available. Other cases show real-time finish excerpts. A speed ratio requires both original and edited runs to pass.

The opening 5.18× was the best verified autocomplete pair, 19.86 → 3.84 seconds. The independently recorded M5 Max MacBook Pro take in chapter 3 measured 15.46 → 3.36 seconds, or 4.61×. The original 20-case MiniWoB++ panel scored 11/20 for the original and 6/20 for the two-row swap.
