# Every browser task in order

[Watch the 1:58 film](https://jtc268.github.io/inkling-2-fast-computer-use/browser-benchmark-in-order.mp4). One recording per task, starting with form fill and add to cart, then five MiniWoB++ tasks and 24 WebArena IDs. Each chapter labels the hardware, checkpoint and native outcome. The footage plays at 1×. Times are for the full task, and paired successes show a shared clock when the source recordings support it. Two WebArena chapters have only an original run.

The opening 5.18× is the fastest passing pair on MiniWoB++ (19.86 → 3.84 s). The filmed MacBook Pro repeat measured 15.46 → 3.36 s, saving 12.11 seconds.

WebArena search chapters use the first paired Mac take from the frozen search-submit checkpoint. The earlier Switch-accessories checkpoint stopped after typing. The current chapter shows the subsequent edit.
