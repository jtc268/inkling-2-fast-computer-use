# Every browser task in order

[Watch the 2:03 film](https://jtc268.github.io/inkling-2-fast-computer-use/browser-benchmark-in-order.mp4). One recording per task, starting with form fill and add to cart, then five MiniWoB++ tasks and 25 WebArena IDs. Each chapter labels the hardware, checkpoint and native outcome. The footage plays at 1×. Times are for the full task, and paired successes show a shared clock when the source recordings support it. Two WebArena chapters have only an original run.

The opening 5.18× is the fastest passing pair on MiniWoB++ (19.86 → 3.84 s). The filmed MacBook Pro repeat measured 15.46 → 3.36 s, saving 12.11 seconds.

The updated search chapters use the first paired Mac recording for each evaluated query. The command-stop checkpoint changed how the model closes a complete browser command. Each row identifies its checkpoint.
